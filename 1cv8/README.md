## Минимум, который нужно помнить

1. `1cv8.exe` — GUI-приложение: вывод только в файл через `/Out`, иначе результата не увидите.
2. Загрузка конфигурации из XML/`.cf` **прерывается на 200 сообщениях** — «мелкие» предупреждения терпеть нельзя.
3. Всегда указывайте `/DisableStartupDialogs /DisableStartupMessages`, иначе процесс может ждать диалога.
4. Проверяйте и код возврата (`EXIT`), и содержимое лога: при `EXIT 0` в логе всё равно бывают предупреждения.
5. Несколько Конфигураторов можно запускать параллельно — только на **разных** базах.
