# Загрузка конфигурации из XML

## Основной путь

```powershell
& $exe DESIGNER /F"$ib" /LoadConfigFromFiles"$tree" /Out"<log>\loadjson.log" /DisableStartupDialogs /DisableStartupMessages
```

- База должна быть **пустой**: остатки прошлой сборки искажают результат.
- Время: 38–49 мин на крупной конфигурации (~120 тыс. файлов; пример: ERP). Запускать в фоне.
- `EXIT 0` — загрузка прошла; **всё равно прочитать лог** и классифицировать сообщения
  (`config/update/diagnostics.md`).
- 200 строк в логе = сработал лимит сообщений, загрузка прервана (см. `1cv8/cli-gotchas.md`).

## Обновление конфигурации БД после загрузки

```powershell
& $exe DESIGNER /F"$ib" /UpdateCfg /Out"<log>\updatecfg.log" /DisableStartupDialogs /DisableStartupMessages
```

Для «чистой» контрольной загрузки обычно не требуется: загрузка в пустую базу и так создаёт конфигурацию БД.

## Частичная загрузка (`/LoadConfigFiles -listfile`)

```powershell
& $exe DESIGNER /F"$ib" /LoadConfigFiles -listfile"<список.txt>" /Out"<log>\loadfiles.log" ...
```

Проверено на практике: **не годится как способ «долить» изменения**. Команда вернула `EXIT 0`, загрузила
7034 файла, но новые объекты в конфигурацию не добавились (размер `DumpCfg` остался прежним). Используйте
полную `LoadConfigFromFiles` — она детерминирована и проверяема.

## Контрольная загрузка готового `.cf`

```powershell
& $exe DESIGNER /F"$chk" /LoadCfg"<итог>.cf" /Out"<log>\check.log" /DisableStartupDialogs /DisableStartupMessages
```

Ожидание: `EXIT 0`, «Загрузка конфигурации успешно завершена», 1,6 мин для 1,5 ГБ. Это проверяет
**целостность файла**, но не корректность типов/данных (см. `config/update/defined-types.md`).

## Что делать при ошибках

1. Снять классы сообщений, определить самый массовый.
2. Найти источник в дереве (скрипт поиска по имени/строке) и починить **в дереве**, а не в базе.
3. Перезапустить загрузку (быстрый цикл: пока есть ошибки — 1–2 мин).
4. Повторять, пока классы не обнулятся; затем полный прогон + `CheckModules` (`config/update/acceptance.md`).

## Грабли

- Не загружайте XML в базу, где уже есть другая конфигурация: получите смесь объектов.
- Не запускайте параллельно две загрузки в одну базу.
- После успешной загрузки **не** сохраняйте базу как `.cf` без `CheckModules` — синтаксис мог не проверяться.
