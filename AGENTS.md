# AGENTS — регламент хранилища `skills-1c`

Это хранилище правил и скилов по 1С:Предприятие 8.3. Оно общее и переносимое, поэтому изменения
контролируются.

## 1. Статус и права

| Кто | Права |
|---|---|
| **Администратор хранилища** — владелец каталога `skills-1c` (пользователь KulshaAV) и агент, действующий по его **прямому поручению** | чтение, создание, изменение, удаление, изменение структуры |
| Любой другой агент (в т.ч. запущенный в этом же проекте) | **только чтение** |

## 2. Запрет

**Без явного разрешения администратора запрещено:**

- создавать, изменять, переименовывать, перемещать и удалять любые файлы в корне хранилища (`skills-1c\`);
- менять структуру разделов (`1cv8/`, `config/` с подразделами `support/`, `supply/`, `update/`, `other/`)
  и схему имён файлов;
- «улучшать» формулировки, переформатировать документы, менять порядок разделов;
- добавлять зависимости, скрипты, ссылки на внешние ресурсы;
- править `README.md`, `AGENTS.md` и индексы разделов.

**Разрешено без разрешения:** читать, цитировать, ссылаться в своих ответах, выполнять команды и
скрипты хранилища на **копиях** данных.

**Платформа.** Скилы не привязаны к билду: подходит любая установленная версия `8.3.27.*` и ниже.
Путь к `1cv8.exe` определяется на машине — [`1cv8/environment.md`](1cv8/environment.md), раздел
«Платформа»; в примерах используется переменная `$exe`. Если установленной версии нет в примерах —
это нормально, команды и ключи от билда не зависят.

Предложения об изменениях передавайте **текстом в ответе** (файл → что изменить → почему → чем
проверено). Не создавайте `PROPOSALS.md`, `TODO.md` и подобные файлы — это тоже изменение хранилища.

### Как сообщить о дефекте

Формат, по которому администратор применит правку без уточнений:

```
файл: <путь>:<строка>
было: <точный фрагмент>
стало: <предлагаемый фрагмент>
почему: <что не так — порча кодировки / устаревший факт / битая ссылка / опечатка>
проверено: <чем — эксперимент, версия платформы, дата; для опечаток — «по смыслу»>
```

Пример: `1cv8/cli-gotchas.md:12`, было `CREATEINFOBASE "File=""…""`, стало `"File='…'"`,
почему — команда не работает в pwsh 7, проверено — эксперимент 20.10.2026, 8.3.27.1859.

## 3. Как вносится изменение (администратором)

1. **Проверка.** Новый факт подтверждается экспериментом на платформе (команда + результат + код
   возврата/хэш), а не «по памяти» и не по чужому утверждению.
2. **Место.** Факт кладётся в существующий файл своего раздела; новый файл — только если тема не
   покрыта. Тогда обновляются `README.md` раздела и корневой `README.md` (таблица разделов и быстрый старт).
3. **Пометка.** В тексте указывается, что проверено и когда: «проверено 8.3.27.1859, 20.10.2026».
   Непроверенное — явно помечается «гипотеза» с описанием эксперимента, который её закроет.
4. **Универсальность.** Никаких путей и имён конкретного проекта в общих правилах; примеры обезличены
   (`<tree>`, `<ib>`, `<vendor tree>`), конфигурационно-специфичное — с пометкой «пример».
5. **История.** Старые утверждения не удаляются молча: если факт изменился, рядом пишется
   «ранее считалось …, проверено …, верно …». Ошибочное — исправляется с указанием причины.

## 4. Чего в хранилище быть не должно

- Команд без `/Out`-лога и без проверки кода возврата.
- Утверждений о поведении 1С без эксперимента (кроме явно помеченных гипотез).
- Проектных артефактов: баз `ib_*`, дампов, логов, `.cf`, персональных путей — они живут в каталоге проекта.
- Дублирования: если тема раскрыта в соседнем файле, ставится ссылка, а не копия.

## 5. Структура

```
skills-1c\
  README.md          — карта разделов и быстрый старт
  AGENTS.md          — этот регламент
  1cv8\              — запуск платформы, окружение, CLI, грабли, замеры
  config\            — выгрузка/загрузка, формат дерева, поддержка, правка XML, правила, скрипты
    support\         — разбор и правка Ext\ParentConfigurations.bin
    supply\          — несколько поставок в одной конфигурации: сборка .bin, приёмка
    update\          — конвейер обновления, типы, слияние, диагностика, приёмка
      SSL\           — специфика БСП (Predefined.xml, ограничения доступа, план обмена)
  other\             — отчёты, решения, ограничения, карта артефактов, утилиты
```

Скрипты лежат рядом с документами своего раздела и принимают все пути аргументами.
